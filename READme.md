# Sistema de Gestão de Insulfilm

API REST para gerenciamento de serviços de insulfilm automotivo.

## Tecnologias

- Node.js + TypeScript
- Fastify
- Prisma + PostgreSQL
- Zod

## Como rodar

Clone o repositório:
git clone <url-do-seu-repositorio>

Instale as dependências:
npm install

Inicie o servidor em modo desenvolvimento:
npm run dev

Servidor disponível em: http://localhost:3333

## Módulos

- Clientes — cadastro e gestão de clientes
- Carros — veículos vinculados a clientes
- Serviços — ordens de serviço com status
- Estoque — controle de películas e materiais
